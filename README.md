# Cub Scout Advancement Tracker

Installable Progressive Web App for local Cub Scout advancement tracking.

## Privacy
The published app contains no Scout names or advancement records. Those are stored only in the browser on the device where the app is used. Do not commit exported backup JSON files to this repository.

## Status colors
- Gray — Uncompleted / no change
- Green — Completed
- Red — Completed & ordered

## Installation on iPhone
After GitHub Pages is enabled, open the Pages URL in Safari, tap Share → Add to Home Screen, enable Open as Web App, then tap Add.
